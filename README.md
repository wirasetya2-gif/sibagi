# SIBAGI

Tampilan aplikasi pencatatan bagi hasil untuk keluarga, versi yang bisa dipasang di HP (PWA).

Repo ini hanya berisi tampilan. Tidak ada data, PIN, atau alamat server di sini: semua data tersimpan di Google Sheet
milik pemilik aplikasi, dan alamat servernya dibawa oleh link undangan pribadi. Tanpa link undangan dan PIN akun,
halaman ini tidak bisa menampilkan apa pun.

Berkas di sini dibuat otomatis oleh skrip perakit. Jangan diedit langsung.
